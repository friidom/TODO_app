# Vision

Build a modern collaborative Kanban project management platform inspired by Jira, Linear and Trello.

The goal is NOT to copy Jira.

The goal is to build a unique application with its own visual identity while providing professional project management features.

# Design Goals

The UI should NOT look like Jira.

Instead it should have:

- rounded cards
- soft shadows
- smooth animations
- modern typography
- colorful board covers
- elegant dark mode
- minimalistic icons
- spacious layouts

The application should feel closer to Linear than Jira while still having its own identity.

---

# Technical Goals

The project should always prioritize:

- maintainability
- scalability
- type safety
- performance
- clean architecture

Quick hacks should be avoided even if they are easier to implement.

---

# Coding Principles

Every new feature should:

- preserve existing functionality
- be reusable
- be modular
- support future collaboration
- avoid database redesign

Before implementing a feature, always ask:

"Will this architecture still work after two years of development?"

If the answer is "no",
redesign first.

---

# Philosophy

This project is intended to become a real production-quality SaaS application rather than a portfolio CRUD project.

Every architectural decision should support long-term growth.
